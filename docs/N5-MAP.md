## Aturan format lesson (ringkas, dari riset)
- explanation 2–4 kalimat ≤20 kata; token JP auto-teal; **bold** ≤1–2 frasa; ==stabilo== MAKS 1/step.
- Maks 2 warna/layar, 3 poin baru/section, tanpa dekorasi di layar instruksi.
- Struktur: arti (1 baris) → pola → contoh (3, 1 morfem berwarna konsisten) → Bedakan! (pasangan minimal) → kuis 3 → rangkum 1 baris.
